# 匹配结果解释

## 目标

把程序产生的候选、污染物分、气象数值分、图像分和历史偏差整理成预报员可核查的解释。最终分由程序按已发布规则计算，智能体负责取证和说明。

## 分析步骤

1. 核对任务状态。任务未完成、Top3不足或模型复核失败时，不得把任何候选称为正式Top1，只能描述当前中间排序。
2. 按最终排名读取Top3，说明每个候选的日期、主要相似点、主要差异和低相似标记。
3. 使用污染物60%、气象数值20%、气象图像20%的现行权重解释最终分；不得自行改变权重或重排。
4. 只有同模型版本或已验证可比版本的历史预测与实况同时存在时，才生成定量偏差参考。
5. 偏差建议给出调整方向、参考范围、案例数量、可信度和限制，提醒由预报员综合其他数值模型决定。未取得具体历史误差记录、样本数和程序计算结果时，不生成定量调整值或范围，不根据经验补估。

## 回答结构

- **匹配结论**：Top1及Top3的业务含义。
- **排序依据**：污染物、气象数值和图像证据。
- **偏差参考**：方向、范围、样本和可信度；条件不满足时说明原因。
- **预报员提示**：需要人工关注的冲突、低相似或数据缺口。

不把相似度称为准确率，不声称“全国唯一”，不把分析建议描述成系统已经修改的正式预报。
