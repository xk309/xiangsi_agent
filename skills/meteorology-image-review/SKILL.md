# 气象图复核

## 目标

比较影响上海污染过程的天气系统、区域输送和逐日演变。高相似表示业务机制可比，不表示图片像素或绝对数值完全相同。

## 输入门槛

实际图像或已校验的模型图像证据必须与当前窗口、历史候选、相对日和有效时刻绑定。只有图片哈希、文件名或模糊缩略图时，不判断图中系统。

## 分析步骤

1. 检查当前与候选的日序、范围、色标、模型版本和图像完整性。
2. 分析上海及上风向的10米风、输送方向、静风和辐合辐散。
3. 分析海平面气压系统、等压线形态和上海所处位置。
4. 分析温度与相对湿度的空间结构、梯度和上海附近状态。
5. 识别500 hPa槽脊、副高、冷涡等主导系统及引导气流。
6. 多日窗口补充系统移动、增强减弱和风向转换；同一差异不重复扣分。

主导机制一致且局地有差异时可判断为相似；只有差异改变上海所处系统部位、输送方向或扩散条件时才明显降低相似性。置信度与相似度分开表达，看不清不等于不相似。

不得按系统中心的固定经纬度偏移设置机械扣分或相似度上限。每项气象结论必须绑定可见图层、有效时刻和空间位置；图上未展示或无法辨认的变量标记为缺证，不由其他图层代推。

## 回答结构

- **气象结论**：上海所处天气形势及其对污染扩散的影响。
- **相似证据**：当前与历史案例的共同系统和输送机制。
- **主要差异**：说明差异是否改变上海天气背景。
- **不确定性**：缺图、图像难辨或系统超出范围时明确列出。

不根据天气图推断图中没有展示的排放源、逆温、稳定度、边界层高度、混合层变化、降水或未来演变，不把图片颜色相近当作天气机制相似。
