# 智能体升级开发任务

## 第一阶段：可运行骨架

- [x] 定义五类业务问题、系统意图和三个领域子图。
- [x] 创建污染过程、气象图复核、匹配结果解释三个Skill。
- [x] 提供LangGraph主图和SSE接口。
- [x] 提供六个只读MCP工具。
- [x] 提供Prefect模拟增量流程和数据中台适配器边界。
- [x] 提供PolarDB pgvector知识表脚本和空RAG接口。
- [x] 提供Docker Compose与内网Prometheus/Grafana配置。
- [ ] 根据产品经理设计接入大屏智能体入口。

验收：在无知识文件、无数据中台正式接口时，服务可以启动；意图能够路由；缺少证据时明确说明；现有匹配接口与页面保持可用。

## 第二阶段：真实数据中台

- [ ] 确认批次、污染物预测、气象预测和实况接口契约。
- [ ] 实现鉴权、分页、超时、重试和限流。
- [ ] 建立批次幂等键与增量游标。
- [ ] 保存模型名称、版本、起报时间、预报日序和源数据版本。
- [ ] 与业务方确认历史气象使用归档预测、实况或再分析场的口径。
- [ ] 实现实况到齐后的案例闭合与补数流程。
- [ ] 完成历史累积数据回灌和完整性报告。

验收：重复批次不重复写入；迟到数据可以补齐；任一匹配结果可以追溯到数据中台批次和版本。

## 第三阶段：专业知识RAG

- [ ] 获取并审核污染物与气象知识文件。
- [ ] 确定Embedding和Reranker模型。
- [ ] 安装`vector`扩展并人工执行知识表脚本。
- [ ] 实现解析、分块、发布、停用和版本管理。
- [ ] 实现向量与关键词混合检索及重排序。
- [ ] 在回答中展示资料名称、版本和页码或章节。
- [ ] 建立专业问题评测集，检查召回率、引用正确性和幻觉。

验收：未发布资料不可检索；每个专业结论可追溯；资料冲突时能展示来源差异。

## 第四阶段：偏差建议与反馈

- [ ] 只使用同时具备历史预测和实况的案例计算定量偏差。
- [ ] 按模型版本、预报日序、污染物和区域检查可比性。
- [ ] 输出调整方向、参考范围、样本数、可信度和限制。
- [ ] 保存任务、终端、采用情况、最终调整值和采用原因。
- [ ] 评测Top3命中率、排序稳定性和建议采用情况。

验收：系统不自动修改正式预报；缺少可比样本时不生成定量范围；所有建议保留计算依据。
